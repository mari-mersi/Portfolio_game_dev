Шаг 1. Создание репозитория на GitHub прямо из IDE
В верхнем меню Visual Studio выбери Git → Создать репозиторий Git.

В открывшемся окне должны быть такие настройки:
* GitHub выбран как удалённый объект — правильно.
* Учетная запись: mari-mersi (GitHub) — ты залогинена, всё ок.
* Владелец: mari-mersi — верно.
* Имя репозитория: Portfolio_game_dev — оставь как есть.
* Шаблон .GITIGNORE: По умолчанию (VisualStudio) — то, что нужно.

Нужно поменять видимость Private → Public

Добавить описание для проекта, например: 
"Персональное портфолио game dev разработчика: витрина проектов, таймлайн опыта, генерация PDF-резюме. ASP.NET Core MVC, EF Core, PostgreSQL, QuestPDF."

Добавить файл README.md — поставить галочку

Нажми «Создать и отправить». Visual Studio создаст репозиторий на GitHub, сделает первый коммит со всем кодом и запушит его.

Шаг 2. Проверка и настройка .gitignore
После создания репозитория файл .gitignore появится в папке твоего проекта, но он не будет виден в обозревателе решений (Solution Explorer) по умолчанию.

Как его увидеть: Нажми на иконку «Показать все файлы» в верхней части обозревателя решений (или включи в настройках Tools → Options → Projects and Solutions → General → Show all files).

Что проверить: Открой .gitignore двойным щелчком. Убедись, что там есть строки:

text
## Ignore Visual Studio temporary files, build results, and
## files generated by popular Visual Studio add-ons.
.vs/
[Bb]in/
[Oo]bj/
*.user
*.suo
Что добавить (для нашего проекта):
Нам понадобится игнорировать локальную базу данных SQLite и логи. Добавь в конец файла:

text
# Local database and logs
*.db
*.db-shm
*.db-wal
logs/
Примечание: Логи лучше игнорировать, так как Serilog будет писать их в папку logs/.

Шаг 3. Синхронизация изменений
Поскольку Visual Studio уже создал репозиторий и запушил изменения, тебе нужно сделать локальную подстройку.

Открой вкладку Git Changes (Git → Git Changes или Ctrl+0, G).

Если ты редактировал .gitignore (добавлял *.db и logs/), эти изменения появятся в списке.

Введи сообщение коммита (например, Update .gitignore for local db and logs) и нажми Commit All (или Commit All and Push).
