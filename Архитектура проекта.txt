Архитектура проекта Portfolio_game_dev:

На сайте есть две зоны:
Public (публичная часть) — то, что видят HR и тимлиды.
Admin (админка) — чтобы добавлять проекты и навыки без правки кода.

1. Контроллеры (Controllers):
1.1. Public-Контроллеры:
BlogController (Статьи/девлоги): Index(int page = 1), Post(string slug)
ErrorController (Обработка ошибок):	Error(), NotFound(), StatusCodePage(int code)
ExperienceController (Таймлайн опыта работы): Index()
HomeController: Index(), About(), Contact() (GET/POST)
ProjectsController (Портфолио — список и детали): Index(), Details(int id), DetailsBySlug(string slug), ByTag(string tag)
ResumeController (Скачивание PDF через QuestPDF): Index(), Download() 
SkillsController (Навыки и стек): Index(), ByCategory(string category)

1.2. Admin-контроллеры (под [Authorize]):
Areas/Admin/Controllers/AccountController - Логин/логаут (Identity)
Areas/Admin/Controllers/BlogController - CRUD для статей
Areas/Admin/Controllers/DashboardController - Главная панель админа со статистикой
Areas/Admin/Controllers/ExperienceController - CRUD для опыта работы
Areas/Admin/Controllers/ProjectsController - CRUD для проектов
Areas/Admin/Controllers/SkillsController - CRUD для навыков

7. Дополнительные инструменты:
EF Core + SQLite/PostgreSQL — для хранения данных.
ASP.NET Core Identity.
Serilog — логирование.
FluentValidation — валидация ViewModel.
Markdig — рендер Markdown в описаниях проектов.
QuestPDF или iTextSharp — генерация PDF-резюме "на лету" из БД.
ImageSharp или ImageSharp.Web — ресайз картинок.
Response Caching / Output Caching — кэш для публичных страниц.
reCAPTCHA — защита формы Contact от спама.

Frontend:
Razor + Tailwind CSS (через CDN или сборку) — быстро и красиво.
Немного JS для анимаций при скролле (AOS.js или GSAP).
Видео/гифки — лучше <video autoplay muted loop> вместо тяжелых GIF.
