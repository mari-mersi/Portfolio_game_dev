# Подробный план реализации Portfolio_game_dev за 14 дней

Каждый день разбит на задачи с конкретными файлами, командами и критериями готовности. В конце дня — чек-лист «готово, если…».

**Стек-решения, зафиксированные заранее (чтобы не отвлекаться):**
- .NET 8, ASP.NET Core MVC
- SQLite (dev) → PostgreSQL (prod)
- EF Core, Identity, Serilog, Markdig, QuestPDF, ImageSharp, FluentValidation (точечно), Tailwind CDN, AOS.js
- Один проект, слоистая папка-структура

---

## День 0 (подготовка, 1–2 часа)

**Задачи:**
1. Установить .NET 8 SDK, Rider/VS, `dotnet-ef` (`dotnet tool install --global dotnet-ef`).
2. Создать репозиторий на GitHub, `.gitignore` для .NET.
3. `dotnet new mvc -n Portfolio_game_dev`.
4. Добавить пакеты одной командой:
   ```
   dotnet add package Microsoft.EntityFrameworkCore.Sqlite
   dotnet add package Microsoft.EntityFrameworkCore.Design
   dotnet add package Microsoft.AspNetCore.Identity.EntityFrameworkCore
   dotnet add package Serilog.AspNetCore
   dotnet add package Serilog.Sinks.File
   dotnet add package Markdig
   dotnet add package QuestPDF
   dotnet add package SixLabors.ImageSharp
   dotnet add package FluentValidation.AspNetCore
   dotnet add package AspNetCore.HealthChecks.UI.Client
   dotnet add package Microsoft.AspNetCore.OutputCaching
   ```
5. Создать структуру папок: `Data/`, `Models/`, `ViewModels/Public`, `ViewModels/Admin`, `ViewModels/Shared`, `Services/Abstractions`, `Services/Implementations`, `Validators/`, `Extensions/`, `Areas/Admin/Controllers`, `Areas/Admin/Views`.

**Готово, если:** проект собирается, структура папок на месте.

## День 1 — Модели, DbContext, миграция, Seeder

**Задачи:**
1. Создать `BaseEntity` (`Id`, `CreatedAt`, `UpdatedAt`).
2. Создать entity: `Project`, `ProjectMedia`, `Skill`, `Experience`, `BlogPost`, `Tag`, `ContactMessage`.
3. Настроить связи:
   - `Project` ↔ `Tag` — M2M (через `ProjectTag` join-таблицу).
   - `BlogPost` ↔ `Tag` — M2M.
   - `Project` → `ProjectMedia` — 1:M.
4. `AppDbContext` с `DbSet<>`, `OnModelCreating`:
   - unique index на `Project.Slug`, `BlogPost.Slug`, `Tag.Slug`;
   - index на `IsPublished + PublishedAt`;
   - каскадное удаление `ProjectMedia` при удалении `Project`.
5. `DbSeeder.SeedAsync` — создать `IdentityUser` админа (email/пароль из `appsettings`), роли `Admin`, 3–5 демо-проектов, 10 навыков, 3 опыта, 2 статьи.
6. `dotnet ef migrations add Initial`, `dotnet ef database update`.
7. В `Program.cs`: подключить `AppDbContext`, Identity, `DbSeeder` в scope.

**Готово, если:** в SQLite-файле есть данные, при запуске приложение стартует без ошибок, админ-пользователь существует.

## Правила, чтобы не утонуть

1. **Один день = одна фича.** Не начинай день с рефакторинга вчерашнего.
2. **Сначала работает, потом красиво.** Верстка — в конце дня.
3. **Коммит в конце каждого дня.** Даже если фича не доделана — `WIP:` префикс.
4. **Не трогай архитектуру после дня 3.** Если хочется — запиши в `TODO.md`, вернёшься после деплоя.
5. **Если застрял на 40 минут — упрощай.** Например, markdown-превью в админке можно выкинуть, PDF — упростить.
6. **Резерв: полдня на баги.** Планируй день 13–14 с запасом.

Удачи. Если по какому-то дню нужен расширенный разбор (например, QuestPDF-шаблон или ImageSharp-пайплайн) — скажи, распишу детальнее.
